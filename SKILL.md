# XXD Panel 032 · 源图一体化定制字标

Turn each supplied photograph into one finished custom wordmark in which source identity and lettering are the same structure. Preserve the real photograph only in paired modes. Extract the subject's most defining contour, proportion, pose, opening, axis, connection, function, or negative shape, then make it construct or transform a native-script letter, character, ligature, counter, terminal, crossbar, stroke junction, or the wordmark's overall silhouette. The main text comes from a verified proper name when available or from a concise user-locale concept grounded in the subject. Minimal colour, exact geometry, refined kerning, medium visual scale, and generous whitespace create a mature identity rather than an icon placed beside a title.

Operational rules follow the shared XXD Panel workflow contract: four combinable modes; source-adaptive ordinary canvases; exact 50/50 paired geometry; linked or independent four-device wallpapers; copy and locale preflight; fresh generation jobs; privacy-preserving raster generation; and one fresh task directory per source and mode. Style-specific sections may refine aesthetics, copy hierarchy, and acceptance criteria but never override this contract.

## Non-negotiable contract

- One source photo may be processed in one or more selected modes. Each selected ordinary mode (`top-bottom`, `left-right`, `design-only`) produces one PNG; selected `wallpaper-pack` produces exactly four separate PNGs. Selecting all four modes therefore produces seven final files per source. Keep every mode in its own task directory and never combine modes, sources, or wallpapers into a grid, contact sheet, or overview.
- Resolve a non-empty ordered set of modes before generation: `top-bottom`, `left-right`, `design-only`, and/or `wallpaper-pack`. Accept one choice, multiple choices separated by `+`, Chinese/English commas or whitespace, natural-language names, or `全部` / `all`. Deduplicate repeated choices and execute in menu order 1→4. If none is specified, ask with the multiline multi-select menu in the workflow. Do not ask again when the set is already clear.
- When the selected set contains `wallpaper-pack`, require a second choice: `linked` or `independent`. A linked pack approves one anchor wallpaper, iPad by default, and makes every other device reference both the original photo and that same anchor. An independent pack gives every device only the original photo. Neither permits resizing or cropping one wallpaper into the others. Do not ask this follow-up when wallpaper mode is not selected.
- Paired modes split exactly 50/50. `design-only` and every wallpaper contain no visible source photograph, no seam, and no reserved photographic panel.
- Exact user pixels have highest priority, followed by an explicit ratio or destination. Otherwise ordinary modes adapt to the complete source: `top-bottom` = `W×2H`, `left-right` = `2W×H`, and `design-only` = `W×H`. Never impose the archived initial brief's 3:4 canvas as a silent default.
- Visible photography remains faithful. Allow only restrained editorial grading and environmental extension needed for an explicitly overridden canvas. Never stretch, distort, repaint, replace, or structurally alter the subject.
- The transformed frame must preserve identity, action, function, and emotion through at least three source-specific cues while embedding at least one defining contour, structure, pose, function, connection, or negative shape into the actual native-script wordmark construction. Text and image must be inseparable: remove the source-derived intervention and the lettering loses its specific identity; remove the lettering and the graphic no longer stands as an independent icon. It is not icon plus title, a generic font with a nearby pictogram, tourism branding, cartoon mascot, decorative badge, stock monogram, pseudo-lettering, or 3D.
- Copy has no silent default. Resolve automatic copy, exact custom copy, or text-free output before image generation. Automatic and custom modes also require a target language or locale. By default, one source-specific copy package is shared verbatim across all selected modes; explicit per-mode copy instructions override it.
- Render no logo, watermark, signature, colour swatch, UI, device mockup, decorative pseudo-text, or unrelated explanatory prose.

## Aesthetic motive lock

Modes and device ratios may change placement and aspect ratio but never the 032 motive. Every transformed frame must visibly express this chain:

**this exact photographed subject or inseparable relation → preserve identity, proportion, pose, direction, action, function, emotion, and at least three defining cues → resolve one short main text from a verified name, subject property, place clue, action state, or supported meaning in the target locale → extract the single strongest contour, opening, axis, connection, proportion, or negative shape → embed it into a letter, character, ligature, counter, terminal, crossbar, stroke junction, or whole-word silhouette → redraw the remaining lettering to share the same geometric DNA, stroke logic, weight, curvature, rhythm, and optical correction → refine kerning and internal/external negative space → use black/white or one restrained source colour on a pale ground → present one unified medium-scale identity with generous whitespace**.

The sophistication comes from discovering a source-specific structural intervention that improves both recognition and letterform—not from hiding a miniature illustration inside every character. Modern identity design, custom lettering, geometric reduction, optical spacing, and cultural visual systems are disciplines rather than a logo template library.

Reject the result as generic when an unrelated photo could replace the source without materially changing the embedded letterform intervention, overall wordmark silhouette, countershape, stroke logic, spacing, or name choice. Also reject icon-left/text-right, icon-above/title-below, unchanged stock type, literal mini-illustrations, excessive altered letters, illegible rebuses, pseudo-foreign glyphs, generic monograms, travel emblems, shield/roundel defaults, gradients, mockups, cartoons, and decoration without identity duty.

## 032 visual system

### One inseparable source-to-letter intervention

- Privately lock at least three source-specific cues across contour, pose/orientation, function, proportion, opening, connection, overlap, negative shape, material, or relational distance.
- Select the one strongest feature that can genuinely improve a native letter, character, ligature, counter, terminal, crossbar, stroke junction, or whole-word silhouette.
- People keep pose, direction, clothing mass, and relational distance; animals keep body rhythm and head direction; plants keep growth gesture; architecture keeps skyline and defining openings; objects and vehicles keep functional silhouette and negative shape; landscapes keep one source-specific terrain or spatial relation.
- Integrate it structurally rather than placing a pictogram nearby. Apply the two-way dependency test: without the intervention the wordmark becomes generic; without the wordmark the intervention is not a separate standalone icon.
- Preserve immediate reading in the resolved language. Modify only the number of glyphs necessary; redistribute weight and geometry across the rest so the whole mark feels authored, not patched.

### Word choice, script, and lettering system

- Use a verified proper name when the source provides one. Otherwise derive one short, memorable word or phrase from subject identity, theme, place clue, action state, or supported symbolism in the target locale. Never fabricate a brand owner, institution, or place.
- Design natively for the resolved script. Chinese and Japanese characters preserve legible stroke structure; Korean preserves syllable-block logic; Arabic preserves joining and contextual forms; Latin preserves letter anatomy. Never force every script into Latin-logo behaviour.
- Give the entire wordmark a shared geometric DNA: consistent stroke weight, terminals, curvature, angles, modulation, counters, baseline, cap or x-height logic, and optical corrections.
- Auxiliary copy is optional and extremely limited—category, region, state, or a short descriptor only when useful. It never becomes a second logo or slogan wall.

### Geometry, spacing, and presentation

- Refine kerning pair by pair, internal counters, external negative space, baseline, overshoot, balance, and optical centre. Mathematical equality may be adjusted when visual equality requires it.
- Keep the mark at a comfortable medium scale on a pale solid or very light neutral ground with generous whitespace. It should work as a mature identity specimen, not a full advertising layout.
- Use black and white or at most one restrained source-derived colour plus necessary neutral contrast. Colour supports identity and structure rather than adding illustration detail.
- Render the mark flat, crisp, and presentation-ready. Reject bevels, extrusion, foil mockups, wall signs, business cards, drop shadows, glossy gradients, lens effects, and 3D product staging.

### Recognition at minimum information

- The wordmark must remain readable at thumbnail size and distinctive in one colour. The source-derived feature must survive small-scale reduction without becoming a blob or disappearing.
- Preserve at least three source cues through the integrated geometry, word choice, overall silhouette, proportion, or negative space, not by adding decorative detail.
- Use one restrained source-derived colour only when it carries the subject's spirit and remains compatible with monochrome reproduction.
- Avoid multicolour segmentation, literal material textures, illustration shading, fixed corporate blue, neon, rainbow gradients, universal beige, and colour unrelated to recognition.

## Copy and typography belong to 032

032 text is the principal designed object: a native custom wordmark whose letterform construction contains the source identity—not a headline placed after an illustration, a caption, UI label, or detached advertising overlay.

- Automatic copy uses a verified proper name when available; otherwise it derives one short brandable word or phrase from the source's identity, theme, place clue, action state, or supported meaning without inventing an organisation or ownership.
- Prefer one restrained title plus zero to two very small supporting elements. A number, place, or year appears only when supplied or reliably established.
- Preserve exact user wording verbatim. Refine an editable direction only within permission while protecting audience, mandatory terms, tone, and semantic phrase breaks.
- Apply the unrelated-image swap test: generic lifestyle words that survive on another source must be rewritten.

Typography has its own 032 construction:

- **Role:** the main identity mark and the carrier of the source-derived graphic intervention.
- **Voice:** concise, confident, modern, memorable, elegant, and professional.
- **Construction:** one short native-script wordmark with one carefully embedded source feature; zero to two small descriptors only when useful.
- **Placement:** one balanced medium-scale mark with generous whitespace; the source feature occupies a glyph, counter, terminal, junction, ligature, or whole-mark silhouette.
- **Material:** flat, crisp custom lettering; never a stock font plus icon, decorative ethnic font, pseudo-glyph, bevelled logo, or mockup.
- **Script:** use native construction, joining, direction, punctuation, spacing, and legibility for the resolved Chinese, Japanese, Korean, Arabic, or Latin locale.

Resolve locale independently from command language:

```text
target market or audience > requested output language > direction language; if none is explicit, ask before generation
```

Localise by transcreation using native wording, rhetoric, punctuation, spacing, shaping, and semantic line breaks. Never infer nationality or audience language from appearance, clothing, scenery, filenames, metadata, or signs.

## Raster generation and privacy

Use one generation call per distinct asset; a wallpaper pack requires four calls. “Custom wordmark”, “logo”, “geometric lettering”, and “identity mark” describe raster image appearance only and never authorise SVG, HTML, CSS, Canvas, diagrams, font-file generation, or programmatic drawing as the artwork.

Judge readiness by actual bitmap capability, not a provider name or one environment variable. Never display, log, persist, or report providers, endpoints, headers, credentials, account identifiers, route configuration, prompts, or response bodies. Do not manually inspect credential files. The bridge's sanitised JSON is the complete allowed diagnostic surface.

An explicit invocation of `/xxd-panel-032` or `$xxd-panel-032` with a source image and requested output authorises generation through any already configured authenticated bitmap route available to the session. Do not ask for a second confirmation solely because the route changes. This does not authorise changing credentials, providers, billing, accounts, or global settings.

Only report generation as unavailable after both built-in capability and the bundled probe fail to establish a usable bitmap route. State the limitation narrowly and never guess the cause or identify the provider. Never substitute code-rendered art.

## Composition commands

```bash

  --out result.png --layout top-bottom

# Source-adaptive left-right
python3 scripts/compose_panel.py --plan --layout left-right --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout left-right

  --out result.png --layout design-only

  --layout design-only --size 1440x3200
```
