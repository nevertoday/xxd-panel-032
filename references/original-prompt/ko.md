# XXD Panel 032 원본 프롬프트 · 한국어 번역

> 읽기와 공유를 위한 충실한 번역입니다. 실행 시 유일한 기준은 [중국어 간체 원문](zh-CN.md)입니다.

제가 업로드한 각 사진을 각각 독립된 고급 디자인 포스터 한 장으로 제작해 주세요. 여러 이미지를 조합하지 말고, 각 사진을 개별적으로 출력합니다. 전체적으로 3:4 세로 구도를 사용하며, 위아래 두 영역의 높이는 엄격히 1:1로 하여 각각 화면의 50%를 차지합니다.

위쪽 절반에는 원본 사진을 유지하고, 주 피사체의 구조, 사실적인 질감, 자연스러운 빛과 그림자, 원래의 색채 분위기를 보존하며, 약간의 고급 사진 색보정만 적용하여 예술 잡지, 독립 출판물과 전시 사진의 질감을 갖게 합니다. 화면 비율에 맞추기 위해 하늘, 지면 또는 환경 배경을 자연스럽게 확장할 수 있지만, 주 피사체를 늘이거나 왜곡하거나 변경해서는 안 됩니다.

아래쪽 절반에서는 사진에서 가장 식별하기 쉬운 **주 피사체, 윤곽, 자세와 서사적 관계**를 추출하여 **간결하고 전문적이며 브랜드 식별성을 갖춘 맞춤형 워드마크 / Logo 그래픽**으로 재구성합니다. 주 피사체 그래픽을 문자 옆에 따로 배치하지 말고, 가장 핵심적인 윤곽, 구조 또는 특징을 글자 자체나 전체 로고 구조에 영리하게 융합하여 그래픽과 문자가 하나로 통일되고 완전하며 식별 가능한 시각 기호가 되게 합니다. 주 피사체가 사람, 동물, 식물, 건축물, 기물, 교통수단 또는 자연경관 중 무엇이든 가장 핵심적인 시각적 특징을 정제하여 간결하고 기하학적이며 그래픽적인 로고 언어로 전환하고, 극히 적은 정보만으로도 한눈에 식별되는 정체성을 유지해야 합니다.

문자는 사진의 주 피사체 명칭, 주제 속성, 장소 단서, 동작 상태 또는 상징적 의미에서 짧은 주요 텍스트 하나를 추출합니다. 원본 이미지 자체에 명확한 고유 명칭이 있으면 주요 표식 명칭으로 직접 전환할 수 있습니다. 명확한 명칭이 없으면 사용자가 지정한 대상 언어로 고도로 압축되고 식별하기 쉬우며 브랜드 워드마크로 적합한 단어나 구를 정제합니다. 범주, 지역, 상태어 또는 짧은 슬로건과 같은 극소량의 보조 작은 글자를 함께 사용할 수 있지만, 반드시 고도로 절제하여 식별 위계를 보완하는 용도로만 사용합니다. 문자와 그래픽이 함께 로고를 구성해야 하며, ‘아이콘 + 제목’의 일반적인 조합이어서는 안 됩니다.

전체 스타일은 **미니멀하고 현대적이며 기하학적이고 눈에 띄며 우아하고, 여백이 충분하고 구도가 균형 잡힌** 상태를 유지합니다. 배경은 연한 단색이나 극히 연한 중성색을 사용하여 깨끗하고 간결하게 유지합니다. 로고는 흑백 또는 극소량의 색상으로 표현합니다. 위쪽 사진에서 가장 정신적 분위기가 두드러지는 한 가지 색을 추출하여 소량 전환할 수 있지만, 전체적으로는 여전히 절제, 전문성과 브랜드화를 우선합니다. 로고는 아래쪽 절반 화면에서 편안한 중간 시각 크기로 유지하며, 너무 크지도 작지도 않게 하고, 성숙한 브랜드 아이덴티티, 문화 시각 시스템 또는 고급 디자인 스튜디오 작품의 완성도를 갖게 합니다.

전체적으로 **그래픽과 문자의 일체화, 주 피사체 식별도, 기하학적 질서, 정교한 자간, 전문적인 레이아웃과 고급스러운 여백**을 강조하여 현대 로고 디자인과 예술 포스터가 결합된 시각적 분위기를 나타냅니다. 여행 포스터 느낌, 단순한 아이콘과 문자, 카툰화, 장식의 적층, 전자상거래 느낌, 저렴한 그래픽과 템플릿 느낌은 피합니다.
