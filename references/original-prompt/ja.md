# XXD Panel 032 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、アート雑誌、インディペンデント出版物、展覧会写真のような質感を持たせます。画面比率に合わせるため、空、地面、または環境の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**被写体、輪郭、姿勢、物語上の関係性**を抽出し、**簡潔でプロフェッショナル、かつブランド識別性を備えたカスタムワードマーク／Logoグラフィック**として再構成します。被写体のグラフィックを文字の横に単独で置くのではなく、その最も重要な輪郭、構造、または特徴を文字自体やロゴ全体の構造へ巧みに融合し、グラフィックと文字を一つの統一された、完全で識別可能な視覚記号にします。被写体が人物、動物、植物、建築物、器物、交通手段、自然景観のいずれであっても、最も核心的な視覚的特徴を抽出し、簡潔で幾何学的かつグラフィカルなロゴ言語へ変換し、ごく少ない情報の中で一目で識別できるアイデンティティを保ちます。

文字は、写真の被写体名、テーマ属性、場所の手掛かり、動作状態、または象徴的意味から短いメインテキストを抽出します。元画像自体に明確な固有名がある場合は、そのままメインロゴの名称に変換できます。明確な名称がない場合は、ユーザーが指定した対象言語で、高度に要約され、識別しやすく、ブランドワードマークに適した単語または短いフレーズを抽出します。カテゴリー、地域、状態を表す語、または短いスローガンなど、ごく少量の補助的な小文字を組み合わせることができますが、高度に抑制し、識別階層を補うものとしてのみ用いなければなりません。文字とグラフィックが共にロゴを構成する必要があり、「アイコン＋タイトル」という通常のコラージュにしてはいけません。

全体のスタイルは、**ミニマル、モダン、幾何学的、印象的、優雅、余白が十分、構図が均衡している**状態を保ちます。背景には淡い単色または極めて淡い中間色を用い、清潔で簡潔に保ちます。ロゴは白黒またはごく少ない色で表現します。上の写真から最も精神的な気質を備えた一色を抽出して少量だけ転用できますが、全体としては引き続き抑制、プロフェッショナル性、ブランド性を優先します。ロゴは下半分の画面内で快適な中程度の視覚サイズに保ち、大きすぎず小さすぎず、成熟したブランドアイデンティティ、文化的ビジュアルシステム、またはハイエンドなデザインスタジオ作品の完成度を備えます。

全体として、**グラフィックと文字の一体化、被写体の識別度、幾何学的秩序、洗練された字間、プロフェッショナルなレイアウト、ハイエンドな余白**を強調し、モダンなロゴデザインとアートポスターを組み合わせた視覚的気質を表現します。観光ポスター感、単純なアイコンと文字の組み合わせ、カートゥーン化、装飾の積み重ね、ECサイト的な印象、安っぽいグラフィック、テンプレート感は避けます。
